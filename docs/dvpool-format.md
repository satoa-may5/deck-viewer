# .dvpool ファイル仕様

`.dvpool` は拡張子を変えているだけの **ZIPファイル**(OSに汎用アーカイブとして誤解されて
勝手に展開されるのを防ぐためのリネーム)。中身は以下の2つ:

```
<プール名>.dvpool  (実体はzip)
├── manifest.json
└── images/
    ├── <画像ファイル1>
    ├── <画像ファイル2>
    └── ...
```

- zipのルート直下に `manifest.json` と `images/` フォルダを置く(サブフォルダに包まない)。
- 圧縮方式は通常のzip(deflate)でよい。パスワード等は不要。

## manifest.json

```json
{
  "poolName": "カードプールの表示名",
  "thumbnail": "001.png",
  "exportedAt": "2026-08-01T10:00:00.000Z",
  "cards": [
    {
      "image": "001.png",
      "name": "カード名",
      "cost": 3,
      "color": "青",
      "parallel": false,
      "type": "character",
      "trigger": "get"
    }
  ]
}
```

### トップレベルのフィールド

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `poolName` | string | 任意 | インポート時のカードプール名の初期値。省略時はUI側でファイル名などにフォールバックする |
| `thumbnail` | string \| null | 任意 | プールのサムネイルに使う画像のファイル名(下記`cards[].image`のいずれかと一致させる)。無ければ`null` |
| `exportedAt` | string(ISO日時) | 任意 | 参考情報、インポート処理では使われない |
| `cards` | array | **実質必須** | 省略した場合`images/`内の画像を全部ファイル名順に読み込むフォールバック挙動になるが、その場合カード名以外のフィールド(`cost`/`color`/`type`/`trigger`/`rarity`/`ap`/`bp`/`attribute`/`generatedEnergy`/`effect`)は全て空扱いになるため、これらを指定したいなら`cards`配列を書くこと |

### `cards[]` の各要素

| フィールド | 型 | 必須 | デフォルト/挙動 |
|---|---|---|---|
| `image` | string | **必須** | `images/`フォルダ内の実ファイル名と完全一致させる(拡張子込み)。一致しないカードはインポート時に無視される |
| `name` | string | 任意 | **カードの表示名**。アプリ内部では`cardName`として保存される。省略/空文字なら空のまま(この場合は下記`name`欄の説明を参照) |
| `cost` | number \| null | 任意 | 省略時は`null`(必要エナジー未設定) |
| `color` | string | 任意 | 省略時は空文字。自由入力扱いだがアプリのUIは`赤`/`青`/`緑`/`黄`/`紫`の5色 + 全色対象カード用の特別な値`全て`を前提にしている。この5色以外の文字列を入れても保存はされるが、UIの色ピル絞り込みには出てこない |
| `parallel` | boolean | 任意 | 省略時は`false`。パラレル(特殊仕様版)カードかどうか |
| `type` | string | 任意 | `character` / `event` / `field` のいずれかのみ有効。それ以外の値(空文字含む)は保存時に自動で空文字に丸められる |
| `trigger` | string | 任意 | `active` / `drow` / `final` / `get` / `raid` / `special` / `color` のいずれかのみ有効。それ以外は自動で空文字("トリガーなし")に丸められる |
| `rarity` | string | 任意 | レアリティ。自由入力(`C`/`U`/`R`/`SR`/`UR`のほか`R★`のような派生表記もそのまま入る)。省略時は空文字 |
| `ap` | number \| null | 任意 | 消費AP。**数値型のみ**受け付ける(文字列で書くと`null`扱い)。省略時は`null` |
| `bp` | string \| number | 任意 | BP。`"2000+"`/`"4000-"`のような接尾辞付きの自由文字列も可(絞り込みでは先頭の数値部分だけを見る)。省略時は空文字 |
| `attribute` | string[] | 任意 | 特徴。文字列の配列。省略時は空配列 |
| `generatedEnergy` | string \| number | 任意 | 発生エナジー。`"1+"`のような接尾辞付きも可。省略時は空文字 |
| `effect` | string | 任意 | 効果テキスト。改行を含んでよい。省略時は空文字 |

> **`name`(カード名)と内部の識別コードについて**
> アプリ側のカードレコードには`cardName`(表示するカード名)とは別に`name`という
> 内部用のフィールドがあり、インポート時の`name`は**画像ファイル名(拡張子除く)から
> 自動生成される**。manifestに書いた`name`は`cardName`の方に入る。
> つまり「表示名を指定したい」なら`name`に書けばよく、識別コードを別途書く必要はない。

### 画像ファイルの制約

- 対応拡張子: `.png` / `.jpg` / `.jpeg`(大文字小文字は問わない)。他形式は不可
- アスペクト比は縦88:横63を想定(強制はされないが、アプリの表示側がこの比率で
  トリミング表示するため、違う比率だと欠けたり間延びして見える)
- ファイル名自体に規則性は不要(`manifest.json`の`image`で紐付けるだけ)。ただし
  `manifest.json`を書かない場合(下記の簡易パターン)はファイル名がそのままカード名に
  使われる

## manifest.json を省略した場合の簡易パターン(参考、通常は使わなくてよい)

`manifest.json`自体が無いzipも許容されるが、その場合は`images/`内の画像をファイル名の
昇順で全部使い、カード名は各画像のファイル名(拡張子を除いたもの)がそのまま採用され、
それ以外のフィールドは全部空/false/nullになる。**個別のメタデータを
持たせたいなら`manifest.json`を書く方が確実。**

## 生成スクリプトへの実装メモ

1. 画像ファイル群を`images/`という名前のフォルダに集める
2. 各画像についてカード名・必要エナジー・色・パラレル可否・タイプ・トリガーを
   決められる場合は`manifest.json`の`cards`配列に1件ずつ書く(決められないフィールドは
   省略してよい、上表のデフォルトが入る)
3. `poolName`(プール名)と、あれば`thumbnail`(サムネイルにしたい画像のファイル名)を
   トップレベルに書く
4. `manifest.json`と`images/`フォルダをまとめてzip化し、拡張子を`.dvpool`にリネームする
   (Node.jsなら`archiver`や`adm-zip`、Pythonなら標準の`zipfile`でよい。zip内の
   ディレクトリ構造がルート直下に`manifest.json`と`images/`が来るようにだけ注意)

## 検証方法

生成した`.dvpool`は、このアプリのホーム画面→「カードプール」タブ→
「カードプールをインポート」→「＋ ローカルからカードプールをインポート」から
選択してその場でインポートできる(`POST /api/pools/import-zip`、multipart形式、
フィールド名`file`)。既存の`.dvpool`(`pool-exports/*.dvpool`)を実例として展開して
比較するのが手っ取り早い。

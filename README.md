# deck-viewer

手持ちのカード画像から、Bandai TCG+ アプリのデッキ一覧画面のような見た目でカードリストを表示するローカルアプリ。

## 使い方

1. `images/` フォルダにカード画像を置く。ファイル名はカードIDと一致させる(例: `KMR-1-012.jpg`)。`.jpg` / `.jpeg` / `.png` / `.webp` に対応。
2. `decks/` フォルダにデッキ定義ファイルを作る(`sample-deck.js` を参考にコピーして編集)。
3. `index.html` の一番下の `<script src="decks/sample-deck.js">` を表示したいデッキファイルに書き換える。
4. `index.html` をブラウザで直接開く(ダブルクリックでOK。サーバー不要)。

## フォルダ構成

```
deck-viewer/
├── index.html        表示ページ
├── style.css          見た目
├── app.js             描画ロジック
├── images/            カード画像(git管理外。各自で用意する)
└── decks/
    └── sample-deck.js デッキ定義(カードID + 枚数)
```

## デッキ定義ファイルの書き方

```js
const DECK = {
  name: "デッキ名",
  cards: [
    { id: "KMR-1-001", count: 4 },
    { id: "KMR-1-002", count: 2 },
  ],
};
```

画像が見つからないカードは斜線のプレースホルダーで表示されるので、画像が揃っていなくてもレイアウト確認ができる。

## 画像について

カード画像自体(スキャン/撮影データ)は著作権の関係もあるため `.gitignore` でgit管理から除外している。実行には各自で `images/` にファイルを用意する必要がある。

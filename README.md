# deck-viewer

手持ちのカード画像からデッキのカード一覧を作れるローカルアプリ。カードの登録
(画像アップロード+トリミング+情報入力)と、Shadowverse風のデッキビルダー、
Bandai TCG+ 風の読み取り専用デッキ表示を備える。Node.js製の小さなローカル
サーバー上で動作し、PWAとしてブラウザ・デスクトップ・モバイルにインストールできる。

**注意: このREADMEはNode.js構成への移行直後のもので、実機での動作確認はまだ
行っていません。** 詳しい経緯・現状のTODOは [CLAUDE.md](CLAUDE.md) を参照。

## セットアップ

Node.jsが未インストールの場合:

```powershell
winget install OpenJS.NodeJS.LTS
```

(インストール後、PowerShellを開き直してから `node --version` で確認)

このフォルダで:

```powershell
npm install
npm start
```

ブラウザで `http://localhost:3000` を開く。

同じWi-Fi内のスマホから使いたい場合は、PCのLAN IPアドレスを調べて
(`ipconfig` の IPv4アドレス)、スマホから `http://<そのIP>:3000` にアクセスする。

## フォルダ構成

```
deck-viewer/
├── server.js          Expressサーバー本体(静的配信 + API)
├── data/
│   ├── cards.json      登録済みカードのデータベース
│   └── decks/*.json    保存したデッキ
├── images/             カード画像(git管理外。各自で用意する)
└── public/              フロントエンド
    ├── index.html       ホーム(デッキ一覧)
    ├── add-card.html     カード追加(画像アップロード→トリミング→情報入力)
    ├── builder.html      デッキビルダー(タップ/スワイプでカードを追加)
    └── deck-view.html     デッキの読み取り専用表示
```

## 使い方

1. ホーム画面の「＋ カードを追加」から手持ちカードを登録する(画像を選ぶ→トリミング→
   カード番号・カード名・必要エナジーを入力→保存)。カード番号がそのまま画像ファイル名になる。
2. ホーム画面の「＋ 新しいデッキ」からビルダーを開き、下の手持ち一覧をタップ/スワイプして
   上のデッキにカードを追加していく。デッキ名を入力して「保存」。
3. ホーム画面のデッキ一覧から「表示」を選ぶと、Bandai TCG+風の一覧画面で確認できる。

## 画像について

カード画像自体(スキャン/撮影データ)は著作権の関係もあるため `.gitignore` で除外している。
`data/cards.json` や `data/decks/*.json` は通常のテキストなのでgit管理に含めており、
他のPCで `git clone` すればカード情報・デッキ情報は引き継がれる(画像だけは別途用意)。
